# Dhruv Singh & Co. — CA Portfolio Site

A React + Vite + Tailwind portfolio site for a Cost accountant.

## Run locally
1. npm install
2. npm run dev
3. Open the URL shown (usually http://localhost:5173)

## Before going live
1. Replace "Dhruv Singh" with your real name — search across src/ (Navbar, Footer, Home, About, Contact).
2. Replace placeholder phone/email/WhatsApp numbers.
3. Replace [X] / XXXXXX placeholders in About.jsx (years of experience, membership no., university).
4. Contact form: sign up free at https://formspree.io, create a form, and paste your
   form ID into FORMSPREE_ENDPOINT in src/pages/Contact.jsx.
5. Update the WhatsApp number in src/components/WhatsAppButton.jsx and Contact.jsx.

## Deploy (free)
1. npm run build   → creates a `dist` folder
2. Go to https://app.netlify.com/drop and drag the `dist` folder in — you get a live URL instantly
3. (Optional) Connect a custom domain in Netlify's site settings
